Cómo funcionan las directivas estructurales

  1. El asterisco * envuelve el contenido en un <ng-template> (no se renderiza solo).
  2. TemplateRef captura esa plantilla en la directiva.
  3. ViewContainerRef es el ancla del DOM donde insertarla.
  4. createEmbeddedView(tpl, contexto) crea cada copia.
  5. El contexto { $implicit: i } habilita let i = $implicit en el template.
